# The Model · FinWise

> Module 6 · Pricing & Monetization. The pricing & packaging recommendation memo for FinWise.

## Stage + model

**Stage:** Stage 1 · Value Creation, Trial-to-paid conversion is only 2% and 60% of paying customers churn within a year - so we haven't demonstrated that users are getting enough value yet.

**Model:** Freemium, This lines up with my revised hypothesis - make organizing finances free, charge for advanced features like financial modeling, forecasts, scenario planning. The reverse trial already drops non-payers to a free version, so scrapping it is less of a change than it sounds. The risk is that if the payoff isn't compelling, freemium just gives us a large free user base that never pays.

_____

## Recommendation

Move from a reverse trial to a freemium model: every new user gets a basic free version that allows them to organize their finances. The advanced features like financial modeling and scenario planning are gated and require a paid subscription.

**The pricing bet:** Packaging matched to value, validating that the free/paid line sits where users feel they need more.

_____

## Model signal

This targets the Financial Modeling Feature Usage % activation indicator - going beyond a certain amount of usage requires a paid subscription.
