## The data pattern

There's no correlation between trial-to-paid conversion and the two leading indicators I chose, Import feature usage % and Financial modeling feature usage %. If activation through these features were the main thing holding conversion back, all that variation should have shown up somewhere in conversion. Revised hypothesis: FinWise’s conversion problem isn’t mainly about reaching features. Many trial users import data and use Modeling, but that use doesn’t turn into a reason to pay. Either these features aren’t the moment users see real value, or something after that moment blocks conversion: price versus perceived value, trial length, or the paywall itself. Note, in my Module 1 exercise I'd already noticed this, and came up with a hypothesis that the biggest growth problem was that trial users were experiencing FinWise as a single-player tool so we should make a collaboration growth loop. But this exercise seemed to force me to focus on the activation part of the funnel, based on the available metrics.

_Metric patterns: Conversion, Ceiling because it holds at about 2% for all 13 months; unlike a classic ceiling, it was already flat when the data starts. Modeling usage, Cliff because it dropped 22% percentage points between Sept and Oct 2024; note, it also dropped sharply between April to May. Import usage, Ceiling because it has held steady between 41% and 45% since July 2024 and seems to have plateaued. Session duration, Cliff because it fell from 12 minutes to 5 minutes between June to August 2024; it has recovered partway but is still well below the first-half level. Sessions/user, Ceiling (tentative) because it has fallen and climbed back a couple times but never exceeded 9 sessions per user, where it has currently leveled off at again._
